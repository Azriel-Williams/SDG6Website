# SDG 6 Awareness Website

## Overview

Interactive website developed to raise awareness about United Nations Sustainable Development Goal 6: Clean Water and Sanitation.

## Features

- Responsive Design
- Dark Mode
- Accessibility Features
- Interactive Statistics
- Educational Content
- Mobile Friendly Navigation

## Technologies

- HTML5
- CSS3
- JavaScript

## Accessibility

- Skip Links
